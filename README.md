Regole per l'inserimento dei dati


-Prodotto: campo obbligatorio, deve contenere testo e non può superare 30 caratteri.

-Prezzo: deve essere un numero maggiore di 0.

-Sconto: deve essere un numero intero compreso tra 1 e 90.


Gestione degli errori


In caso di inserimento di dati non validi:

-Viene visualizzato un messaggio di errore sotto il campo interessato.

-Il campo non valido viene evidenziato graficamente.

-I dati già inseriti vengono mantenuti, evitando di dover compilare nuovamente il form.
